# تطبيق قائمة مهام متطور

واجهة ويب بسيطة لكنها قوية لإدارة قائمة مهامك اليومية باستخدام HTML وCSS وJavaScript فقط، مع دعم كامل للغة العربية ووضعَي النهار والليل.

## المزايا الرئيسية
- 🌙 **تبديل السمات** بين الوضعين الفاتح والداكن مع تذكّر آخر اختيار تلقائيًا.
- ✅ **تحديد المهام كمكتملة**، مع تصفية ذكية للحالة (الكل، النشط، المنجز) وتصفية إضافية حسب أولوية المهمة.
- ✏️ **تحرير سريع للمهمة** عبر الزر المخصص أو النقر المزدوج على النص.
- 🎯 **اختيار أولوية المهمة** (عالية، متوسطة، منخفضة) مع إمكانية تدويرها بنقرة واحدة على رمز 🎯.
- 🔍 **بحث لحظي** داخل المهام لتجد ما تبحث عنه بسرعة.
- 📊 **بطاقات إحصائية واضحة** تلخّص المهام النشطة، المنجزة، الإجمالية ونسبة التقدّم الحالية.
- 🧹 **حذف المهام المنجزة دفعة واحدة** مع رسائل فارغة تساعدك على معرفة نتائج البحث الحالي.
- 💾 **حفظ تلقائي** لكل مهامك في المتصفح باستخدام LocalStorage مع تنبيه واضح عند تعطيل التخزين.
- 📱 **تصميم متجاوب** يعمل بشكل رائع على الهواتف والشاشات الكبيرة.

## طريقة التشغيل
1. قم باستنساخ المستودع أو تحميل الملفات إلى جهازك.
2. افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا مثل:
   ```bash
   python -m http.server 8000
   ```
   ثم انتقل إلى العنوان `http://localhost:8000/`.
3. أضف مهامك عبر حقل الإدخال واختر الأولوية المناسبة ثم اضغط زر **إضافة**، وسيظهر تنبيه تحت القائمة إذا كان المتصفح لا يسمح بالحفظ التلقائي.
4. استعن بشريط البحث أو مرشحات الحالة والأولوية للوصول إلى ما تريده، واضغط على زر **حذف المنجز** لتنظيف القائمة بسرعة.

> تلميح: يمكنك تعديل أي مهمة بالنقر المزدوج عليها، ثم الضغط على Enter للحفظ أو Esc للإلغاء.

استمتع بتنظيم يومك! لا تتردد في تخصيص الواجهة أو إضافة مزايا جديدة حسب احتياجاتك.
